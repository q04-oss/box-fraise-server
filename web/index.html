What both of them are for

Making Whyte Avenue and Jasper Avenue pedestrian only. That is the purpose of the run club and the purpose of this board. Whyte is the most walked street in Edmonton and it is still organised around moving cars through it. Jasper is the same argument downtown.

Running down a street is the cheapest way to find out who it was built for. The board exists so that people who have never come to a run are still running the same streets for the same reason, and so there is a number to point at when somebody asks how many of us there are.
